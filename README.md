# 우리 가족 여행 기록

한국어 가족 여행 아카이브. 빌드 없이 배포하는 정적 사이트입니다.

## 구성
- 우리 가족 여행 / 우리가 다녀온 곳 / 여행 이야기 / 여행 사진첩 / 가족 전용 앨범
- 첫 기록: [2026 호주 가족여행](https://ksangki.github.io/australia-family-2026/)
- 기존 호주 저장소·배포는 수정하지 않습니다.
- 가족 전용 앨범은 별도 비공개 GitHub 저장소로 연결합니다. 가족의 GitHub 계정과 저장소 초대 권한으로 접근하며 이 공개 사이트 자체에는 인증·원본 저장 기능이 없습니다.

## 실행 및 배포
`python3 -m http.server 8000` 실행 후 브라우저에서 확인하세요.
GitHub Pages의 배포 원본을 main 브랜치 루트로 설정합니다.
모든 로컬 참조는 상대 경로이므로 /family-travel/ 하위 배포를 지원합니다.

## 2025 오사카 가족여행
`osaka-2025.html`에 공개 대표 풍경 사진 3장을 정리했습니다. 공개 동의를 받은 가족 소유 사진이며, 원본은 저장소에 포함하지 않습니다. JPEG를 새로 인코딩하여 EXIF·GPS·기기 정보·원본 파일명을 제외했습니다. 가족 인물·여권·예약·티켓 사진과 동영상은 제외했습니다. 정확한 여행 기간은 미확인 상태로 연도만 표시합니다. 가족 사진의 저작권은 가족에게 있으며 기존 시드니 사진의 CC 라이선스와 별개입니다.

## 메타데이터 기반 여행기

- `hong-kong-2024.html`: 2024.5.26~27 디즈니 리조트·파크 사진 기록. 전체 여행 기간은 미확인.
- `osaka-2025.html`: 2025.6.1~6 일본 방문 사진을 오사카·교토 코스로 재구성. 6/7 국내 사진은 현지 코스에서 분리.
- `australia-2026.html`: 현재 원본과 기존 호주 여행기 편집 근거를 나눠 표시한 요약. 기존 호주 저장소는 수정하지 않음.
- `travel-records.json`: 공개 가능한 요약 데이터만 포함. 원본 파일명·사적 주소·전체 GPS·촬영 시각은 없음. 지도 좌표는 공개 장소 대표점.
- `travel.js` / `travel.css`: 날짜·활동 필터와 공개 장소 동선 개략도. Google 지도에는 공개 장소의 대표점만 전달하며 사적 위치는 보내지 않음.
- 내용 수정: `travel-records.json`을 수정한 뒤 `python3 scripts/render-records.py`로 세 페이지를 재생성. 빌드 의존성은 없음.

사진 493장·동영상 44개의 상세 분류, 원본 연결과 날짜별 가족 사진은 비공개 저장소 albums/ 및 analysis/에만 보관합니다. 원본은 변경하지 않습니다.
사진 476장에 유효 GPS가 남아 있고 공유 동영상 8개는 원촬영일 미확인으로 분리했습니다. 이번 공개 업데이트는 기존 승인된 풍경 사진 4개만 사용합니다.

## 2022 제주도 가족여행
`jeju-2022.html`에 6월 1~5일의 사진 장면을 날짜별로 정리했습니다. 사진 359장 중 촬영일 345장, 촬영일 미확인 14장. 유효 GPS는 0개이므로 지리적 경로 대신 장면 순서도를 사용합니다. 수국 정원·어린이 체험 전시의 시설 이름은 미확인으로 표시합니다. 원본과 미리보기는 비공개 저장소에만 보관하며 공개 가족 사진을 추가하지 않았습니다.

## 2023 도쿄 디즈니 가족여행

## 선별 대표 사진 공개 (2026-10-24)
사용자 요청으로 2026 호주를 제외한 네 여행에 대표 장면 4장씩을 선택적으로 공개했습니다. 제주 표지 1장을 포함해 새 공개 사본은 17개입니다. 인물이 함께 나온 장면을 포함하며, 원본은 비공개에 두고 공개 사본은 긴 변 1000px 이하로 새로 인코딩해 EXIF·GPS·XMP·기기 정보를 제거했습니다. 원본 파일명 대신 장면 번호로 보관합니다. 상단·여행 카드·날짜별 사진은 작은 프레임과 원본 비율로 배치하며 2026 호주 페이지는 변경하지 않았습니다. 이전 기록의 ‘공개 사진 추가 없음’은 당시 상태이며 이 항목이 현재 공개 범위입니다.

`jeju-2021.html`: 원본 사진 439장, 2021.6.24~27 촬영일 433장, 촬영일 미확인 6장. 유효 GPS가 없어 지도 대신 장면 순서도 사용. 숙소 정원·물놀이·해안 산책·스누피가든을 정리했습니다. 원본과 상세 가족 사진은 비공개, 작은 대표 사진 4장과 표지 1장만 공개합니다. 공개 사본은 긴 변 1000px 이하이며 EXIF·GPS·기기 정보를 제거했습니다. 원본 ZIP은 수정·삭제하지 않았습니다.

## Google 지도와 확장 사진첩 (2026-10-25)

- 메인과 각 여행의 대표 사진을 실제 여행 사진으로 다시 선별했습니다. 메인 사진첩에서 여섯 여행의 사진첩을 열 수 있습니다.
- 공개 사진첩: 2026 호주 12장, 2025 오사카·교토 18장, 2024 홍콩 12장, 2023 도쿄 16장, 2022 제주 16장, 2021 제주 16장. 사용자 요청으로 선별 공개한 사진 총 90장입니다. 이전 공개 사본은 기존 링크 보존을 위해 유지합니다.
- 원본은 비공개 저장소에 보존합니다. 새 공개 사본은 긴 변 1600px 이하로 재인코딩하고 EXIF·GPS·XMP·기기 정보와 원본 파일명을 포함하지 않습니다. 상세 선별 대응표는 비공개 저장소에만 보관합니다.
- 각 날짜의 이야기에 해당 날짜의 사진을 여러 장 배치합니다. 사진을 누르면 확대할 수 있습니다.
- Google 지도 iframe에 공개 장소를 표시하고 버튼으로 장소를 전환합니다. API 키는 필요하지 않습니다. 지도 로딩 시 Google에 일반적인 브라우저 연결 정보와 선택한 공개 장소가 전달됩니다.
- 홍콩·일본·호주는 Google Maps URL의 경유지 기능으로 전체 동선을 별도 열 수 있습니다. 표시되는 경로는 Google의 추천이며 실제 가족 이동 궤적이 아닙니다.
- GPS가 없는 제주는 확인된 9.81파크와 스누피가든만 검색 지도로 연결합니다. 이름 미확인 시설·숙소의 위치나 경로를 추정하지 않습니다.
- 재생성: `python3 scripts/render-records.py`. 사진과 지도 데이터의 원본은 `travel-records.json`입니다. 기존 별도 `australia-family-2026` 저장소는 변경하지 않습니다.

## 홍콩·마카오 확대 및 메인 가로 프레임
2024년 여행은 홍콩·마카오를 함께 정리했습니다. 기존 30장에 새 원본 661개를 더해 사진 646장·동영상 45개를 비공개 보관합니다. 5/26~6/1 날짜별 기록과 마카오 대표 사진 8장을 추가했습니다. 동일 사본 30개와 영수증·티켓 이미지 3개는 추가 백업에서 제외했으며 로컬 원본은 수정·삭제하지 않았습니다.
메인 여행 카드와 대표 사진 목록은 object-fit:cover로 가로 프레임을 채웁니다. travel-records.json의 homePosition으로 사진별 표시 위치를 관리합니다. 상세 여행기·사진 확대는 원래 사진 비율을 유지합니다. 공개 원본 이미지 자체를 자르거나 비공개 원본을 덮어쓰지 않습니다.

## 전체 동선 요약
각 여행기의 동선 영역은 날짜별 방문 순서를 페이지 안에서 바로 보여 줍니다. 홍콩·마카오는 overviewGroups 데이터로 지역별 흐름과 대교 이동을 구분하며, 다른 여행은 날짜별 기록에서 요약을 생성합니다. 각 카드는 해당 날짜 기록으로 연결되며 기존 날짜 필터를 해제해 숨겨진 기록도 볼 수 있습니다. 기존 Google 전체 동선 링크는 그대로 유지하고, 장소별 Google 지도는 접어서 필요할 때 펼칩니다. 요약은 방문 순서이며 실제 주행 경로·거리·소요시간이 아닙니다.
