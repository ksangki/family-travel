# 우리 가족 여행 기록

한국어 가족 여행 아카이브. 빌드 없이 배포하는 정적 사이트입니다.

## 구성
- 우리 가족 여행 / 우리가 다녀온 곳 / 여행 이야기 / 여행 사진첩 / 가족 전용 앨범
- 첫 기록: [2026 호주 가족여행](https://ksangki.github.io/australia-family-2026/)
- 기존 호주 저장소·배포는 수정하지 않습니다.
- 가족 전용 앨범은 별도 비공개 GitHub 저장소로 연결합니다. 가족의 GitHub 계정과 저장소 초대 권한으로 접근하며 이 공개 사이트 자체에는 인증·원본 저장 기능이 없습니다.

## 실행 및 배포
`python3 -m http.server 8000` 실행 후 브라우저에서 확인하세요.
GitHub Pages의 배포 원본을 main 브랜치 루트로 설정합니다.
모든 로컬 참조는 상대 경로이므로 /family-travel/ 하위 배포를 지원합니다.

가족 사진·위치 메타데이터·개인 정보·비공개 앨범 URL은 포함하지 않습니다.
추가 사진은 공개 동의와 메타데이터 제거를 확인한 사본만 이 저장소에 넣으세요.
비공개 앨범은 별도 인증이 있는 서비스에 보관해야 합니다. HTML 비밀번호나 숨긴 링크는 접근 통제가 아닙니다.

## 2025 오사카 가족여행
`osaka-2025.html`에 공개 대표 풍경 사진 3장을 정리했습니다. 공개 동의를 받은 가족 소유 사진이며, 원본은 저장소에 포함하지 않습니다. JPEG를 새로 인코딩하여 EXIF·GPS·기기 정보·원본 파일명을 제외했습니다. 가족 인물·여권·예약·티켓 사진과 동영상은 제외했습니다. 정확한 여행 기간은 미확인 상태로 연도만 표시합니다. 가족 사진의 저작권은 가족에게 있으며 기존 시드니 사진의 CC 라이선스와 별개입니다.

## 메타데이터 기반 여행기

- `hong-kong-2024.html`: 2024.5.26~27 디즈니 리조트·파크 사진 기록. 전체 여행 기간은 미확인.
- `osaka-2025.html`: 2025.6.1~6 일본 방문 사진을 오사카·교토 코스로 재구성. 6/7 국내 사진은 현지 코스에서 분리.
- `australia-2026.html`: 현재 원본과 기존 호주 여행기 편집 근거를 나눠 표시한 요약. 기존 호주 저장소는 수정하지 않음.
- `travel-records.json`: 공개 가능한 요약 데이터만 포함. 원본 파일명·사적 주소·전체 GPS·촬영 시각은 없음. 지도 좌표는 공개 장소 대표점.
- `travel.js` / `travel.css`: 날짜·활동 필터와 공개 장소 동선 개략도. 외부 지도 서비스에 좌표를 보내지 않음.
- 내용 수정: `travel-records.json`을 수정한 뒤 `python3 scripts/render-records.py`로 세 페이지를 재생성. 빌드 의존성은 없음.

사진 493장·동영상 44개의 상세 분류, 원본 연결과 날짜별 가족 사진은 비공개 저장소 albums/ 및 analysis/에만 보관합니다. 원본은 변경하지 않습니다.
사진 476장에 유효 GPS가 남아 있고 공유 동영상 8개는 원촬영일 미확인으로 분리했습니다. 이번 공개 업데이트는 기존 승인된 풍경 사진 4개만 사용합니다.

## 2022 제주도 가족여행
`jeju-2022.html`에 6월 1~5일의 사진 장면을 날짜별로 정리했습니다. 사진 359장 중 촬영일 345장, 촬영일 미확인 14장. 유효 GPS는 0개이므로 지리적 경로 대신 장면 순서도를 사용합니다. 수국 정원·어린이 체험 전시의 시설 이름은 미확인으로 표시합니다. 원본과 미리보기는 비공개 저장소에만 보관하며 공개 가족 사진을 추가하지 않았습니다.

## 2023 도쿄 디즈니 가족여행
`tokyo-2023.html`에 2023.10.27~31 사진 기록을 정리했습니다. 중복을 제외한 사진 254장·동영상 36개. 원본은 비공개 저장소에만 보관하며 공개 가족 사진을 추가하지 않았습니다. 10/28 리조트 주변 산책·쇼핑, 10/29 디즈니씨, 10/30 디즈니랜드를 구분합니다.
